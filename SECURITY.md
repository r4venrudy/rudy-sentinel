# Security

Experimental kernel software for isolated research VMs. Not supported for production deployment or as an antivirus replacement.

Use minimal synthetic reproductions and sanitized diagnostics in public issues. Never post credentials, private keys, personal telemetry or sensitive command lines/case exports. Review kernel synchronization/lifetime, device authorization, IOCTL validation and untrusted event parsing carefully.

No arbitrary memory-access, termination, injection, concealment or security-bypass interface is exposed. Administrators retain supported control of the driver and agent.
